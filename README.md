# Big Data — Matrix Multiplication

Individual empirical studies of matrix multiplication for the BIG DATA course
(Grado en Ciencia e Ingeniería de Datos, ULPGC, 2026-2027).

| Assignment | Topic | Folder | Submission tag |
|---|---|---|---|
| 1 | Basic implementations in Python, Java and C | [`assignment-1/`](assignment-1/) | `assignment-1` |
| 2 | Optimised approaches and sparse matrices | `assignment-2/` | `assignment-2` |
| 3 | Parallel multiplication (optional vectorisation) | `assignment-3/` | `assignment-3` |
| 4 | Distributed multiplication | `assignment-4/` | `assignment-4` |

Each assignment folder is self-contained and has its own README with exact
build and run instructions. Each submitted version is frozen with a git tag.
